OFFLINE

SMALL DRIVE · REAL ENGINEERING

盘很小，做的事情不少。A small drive. A lot of engineering.

让“装进去”，变成“带过去就能用”。Making portable AI easier to start and carry.

设备钱包，免手填 KeyDevice wallet, less setup

随盘凭证连接云端钱包，打开钱包、一键进入充值。使用虾盘云免手动填写 API Key。A portable credential connects to your cloud wallet. Open it and top up, without manually entering a Xiapan Cloud API key.

UBench，用实测选盘UBench for storage testing

自研开源跑分工具，减少系统缓存干扰，关注顺序与 4K 随机 I/O，用测试指导硬件方案。Our open-source benchmark reduces OS-cache interference and measures sequential and 4K random I/O to inform hardware choices.

缓存留本机，工作随盘Local cache, portable work

Lite 复用本机程序缓存；Pro 另优化编译与受管浏览器目录。减少盘上重复读写，保留盘内工作状态。Lite reuses a local program cache. Pro also redirects compilation and managed-browser data to the host, reducing repeated USB I/O while keeping work state portable.

exFAT，逐项验证兼容exFAT, tested by platform

Lite Mac ARM 候选版已通过实体 exFAT U 盘集成测试；Pro 新版继续验收。按版本与平台说明支持范围。The Lite Mac ARM candidate passed integration tests on a physical exFAT USB drive. The latest Pro adaptation is still being validated.
