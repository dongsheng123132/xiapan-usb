## 校验与使用
1. Windows：双击 `校验母盘.ps1`；Mac：终端 `bash 校验母盘\ Mac.command`。
2. 插盘即用：双击 `开始使用.cmd`（Win）或 `启动 Mac.command`（Mac）。
3. 随盘 AI：打开页面 → 随盘 AI 应用 → 点「打开」启动 U-Claw / U-DSH（首次打开会有确认提示）。
4. 数据随盘：AI 会话、配置、凭据都保存在 U 盘内，换电脑不变。

## 已知边界
- u-claw 完整便携包约 1.4GB、u-dsh 约 0.9GB（含三平台 node + 内核依赖），体积换完备性，插 Windows/Mac 均免下载。
- exFAT 格式：Windows/Mac 双系统可读写；Mac 上 `.command` 双击权限提示见上文终端替代命令。
- 真实模型对话需在应用内配置 API Key（u-claw 首次启动若未配置会自动打开配置页）。

## 0.5.5 修复补丁（2026-10-15，已在以上 zip 中）

实际投盘（F 盘 exFAT）验证发现并修复的两个启动问题，**本版已含修复**：

1. **U-Claw（u-claw）exFAT 启动崩溃修复**：
   - 根因：打包时手动装 OpenClaw，未跑 setup 的 exFAT 兼容补丁（`patch-portable-filesystem.mjs`）→ OpenClaw 原子写文件在 exFAT 上做严格身份校验失败（`path-mismatch`）崩溃。
   - 修复：已应用补丁（openclaw-cli-shim / diagnostic-stability 两个 bundle 走 `verify-content-with-lock` 兼容路径）；`portable-filesystem.mjs` 增加 Windows exFAT/FAT32 零 inode 识别；补 `.uclaw-runtime-platform` 标记；`runtime-requirements.mjs` 支持三平台标记（win32-x64 + darwin-arm64 + darwin-x64）。
   - 已在 F 盘（exFAT）实测：启动成功，网关 `/ready` 返回 200。
   - u-claw 仓库已提交推送（commit 20d99c8）。
2. **U-DSH 启动脚本修复**：
   - 根因：自写启动器 `web-launch.js` 是 CommonJS，被 DSH 内核的 `"type":"module"` 误当 ESM 加载崩溃；且旧版 `--patch` 参数在 DSH 0.2.0-rc.2 已移除，启动即报错。
   - 修复：启动器改为 `web-launch.cjs`（CommonJS 显式），去掉 `--patch`，改用 `--no-open` 由启动器带完整 token URL 打开浏览器（`.bat`/`.command` 已同步）。
   - 已在 F 盘（exFAT）实测：Web 内核就绪并自动打开浏览器。
3. 投盘提示：K 盘被回读校验抓出 3 万+ CRC 坏文件（**K 盘是坏盘**，与 zip 无关——同批 zip 在 F/G 盘全部解压校验通过）；请弃用 K 盘换新盘。

## 0.5.5 修复补丁 2（2026-10-17，PicoClaw 启动冲突修复，压缩包已全量重打）

投盘验证中发现并修复的启动问题（**本版已含修复，lite / part1-3 / 全量包均已重打**）：

**“本盘已有 PicoClaw 服务运行，请先从原窗口退出”误报修复**：
- 根因：启动器读取本盘 `data/pico/.picoclaw.pid`，只要对应端口 `/health` 返回 200 就**无条件拒绝启动**。正常退出后 pid 文件残留，下次插盘启动即误报，必须手动退出旧窗口（或先 kill 旧进程）才能再启动。
- 修复：启动前对 pid 做**三重身份核验**——① `/health` 返回的进程 pid 必须等于 pid 文件记录；② 进程镜像路径必须位于本盘 runtime 缓存目录（`runtimeCacheDirectory` 或 `<盘根>/runtime/picoclaw`）；③ 用 `.security.yml` 的 channel token 完成 ws 握手。只有确认是本盘遗留的**孤儿进程**才自动停止并重启，同时清理陈旧 pid 文件；无法确认身份的进程**保留原报错文本，绝不误杀未知进程**。
- 随盘源码已同步：`gateway.go` 更新（移除“health 200 即拒绝”拦截）+ 新增 `gateway_orphan.go`（Windows / Unix 平台实现）及对应测试。
- 验证：`go vet ./...` 通过、新增单测全绿（含 ws 鉴权握手用例）、`go test ./...` 全绿；F 盘已部署新构建（`sha256=ea4de953…`，版本 `0.5.5-portable-preview`），插盘启动不再误报。
- **全平台重建**：修复影响所有平台启动器，已按 `build.ps1` 重新构建 Windows / macOS(arm64) / macOS(x64) / Linux 四平台产物并替换入盘（盘根 `虾盘.exe`、`app/bin/xiapan-macos-arm64`、`app/bin/xiapan-macos-x64`；`app/build-manifest.json` 同步更新，source_commit=`39e48b9`，source_fingerprint=`75952bcb…`）。
- 源码仓库：xiapan-usb `codex/u-picoclaw-portable` 分支已提交并推送（`39e48b9`）。
