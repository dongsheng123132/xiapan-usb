## 本轮 Mac 适配

- 首页使用 Mac 系统信息示例，快捷键显示 Command；版本来自运行程序。
- 工具目录按当前系统过滤。Mac 显示 5 项系统工具，不混入 Windows 便携软件、选装软件与 PC 救援资源。
- 网络检查显示 Mac 的真实接口、状态和地址，并提供无线诊断入口；说明匹配 macOS，不沿用 Windows 硬件 ID、INF 和设备管理器流程。
- 启动救援页按 Apple Silicon / Intel 提供 [Apple 官方恢复说明](https://support.apple.com/zh-cn/102518)。系统体检未读取到的可用内存显示“未获得”，并给出系统工具入口。
- 中英快速入门和 Mac 文件校验入口随母盘生成。修复 CRLF 清单在 Mac 上把回车误认成文件名的问题；清单统一生成 LF，Mac 校验同时兼容 CRLF。

## 复制与试用

1. Windows 使用 `开始使用.cmd` / `Start Windows.cmd`，校验使用 `校验母盘.ps1` / `Verify Files.ps1`。
2. Mac 使用 `启动 Mac.command` / `Start Mac.command`，校验使用 `校验母盘 Mac.command` / `Verify Files Mac.command`。若双击脚本不能启动，在终端输入 `sh` 和一个空格，将脚本拖进去再回车。首次系统信任与文件访问提示按目标 Mac 处理，详见盘根快速入门。
3. 每位客户从空白母盘复制。使用中的客户盘保留其自己的 `data/`，不要用模板覆盖 Key、钱包、会话或工作文件。
4. 在页面点击“退出”，关闭打开的维护工具，再安全弹出 U 盘。

Mac mini 实体盘上的 **虾盘 Mac 0.5.4 验收/** 可直接试用；它是 ARM 验收子集，Windows 工具与 Intel 运行时未复制，其 SHA256SUMS 只覆盖该子集。正式制盘使用本机上面的完整母盘。
