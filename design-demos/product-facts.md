# 产品事实卡（design 用）

> 事实来源：本仓库源码 / docs/PRODUCT.md / web/index.html，2026-10-31 核实。

## 产品
- 名称：虾盘 · U-PicoClaw 随身 AI（Lite）；对外也叫「虾盘随身 AI 盘 / U盘精灵」
- 一句话：把 AI 配置、会话、记忆、技能和工作文件装进 U 盘，换台电脑接着干；顺带电脑维护工具包
- 引擎：PicoClaw v0.3.1（冻结基线，客户盘不自升级）；官方完整界面按需打开
- 平台：Windows x64 / macOS Apple Silicon / macOS Intel（同仓同配方）；Linux 首轮不承诺
- 形态：本地 HTTP 服务 + 浏览器界面（自建轻量首页）+ 官方完整 PicoClaw 界面（进阶）

## 核心模块（现状）
1. 轻量首页（自建 Web UI）：对话、模型设置、设备钱包、维护工具包入口
2. 持久 PicoClaw Gateway：推理、工具、技能、原生会话
3. 设备钱包：虾盘云随盘充值 / 自带 OpenAI 兼容 API
4. 维护动作核心：体检、进程、网络、启动项、驱动、工具启动（GUI/CLI/MCP 共用）

## 界面现状（web/index.html）
- 左侧导航：AI 对话 / 电脑维护工具包 / 盘内资源 / 启动救援；底部设备钱包 + 设置随盘状态
- 顶栏：语言切换、对话记录、模型设置、钱包·充值、快捷命令、专业模式、退出
- 首页欢迎：4 张 starter 卡（启动项 / 网络 / 写点东西 / 无法启动）+ 4 条 strengths（随身AI/钱包随盘/程序缓存/维护工具包）
- 输入区：engine 选择（AI 助手 / 本地工具）、发送、断网应急入口

## 本次设计目标（用户拍板）
- 从「工具盘」改向「随身 AI 办公搭子」（迷你 DSH/Codex 的完整感）
- 主区 = 对话 + 文件/工作区（新增文件夹功能，目前缺）
- 右上角 = 快速动作（钱包 / 模型设置 / 维护工具 / 完整 PicoClaw）
- 标准：苹果 HIG（层级、和谐、一致、自适应、聚焦；44pt 目标、系统字体、单一强调色、语义色）

## 用户已知偏好（AGENTS.md）
- 反感 AI 味 UI（深色大屏 / LCD 字体 / 英文装饰 / 渐变发光全否）
- 政务界面 = 浅色卡片化 + 单蓝强调 + 深蓝题头红标线
- 常让 kimi-k3、fable 当设计评审

## 未验证（不写进稿子里当事实）
