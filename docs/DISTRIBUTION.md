# 开源软件与预装实体盘

产品边界与技术路线统一见 [U-PicoClaw 产品设计](PRODUCT.md)。本文仅说明发行、资源与交付约定。

## 产品价值

源码免费公开；实体盘销售的是硬件、预下载资源、可复现配置、出厂检测和约定的支持。可以同时提供免费下载自装与付费成品盘，不把已公开的上游软件宣传为独家自研模型。

产品是随身 AI U 盘：自建快速界面 + 按需官方完整界面，共用持久 PicoClaw；设置随盘、快捷充值、本机公开程序缓存，附带断网应急的传统维护工具与驱动资源。

| 组成 | 内容 | 交付方式 |
| --- | --- | --- |
| AI 程序 | 固定版本 PicoClaw、便携入口、随盘配置与钱包功能 | 按目标平台构建、校验；无需用户自行安装开发环境 |
| 应急工具 | 已适配的诊断/修复动作和传统工具 | 按平台列出真实能力；断网不要求云端额度 |
| 驱动资源 | 有明确硬件/系统范围及验证记录的资源 | 独立清单；不把旧网卡库宣传为全型号驱动 |

不再发行自带本地大模型/推理引擎，也不在本仓库加入 OpenClaw 或其他 Agent 套装。AI 程序包和完整资源盘分别公布体积；联网模型的响应速度与程序启动速度分别验证。

定价以硬件采购、写盘与检测、包装物流、平台费用、售后和合理利润为基础。先小批量验证购买意愿、退货原因和支持成本，再扩大型号；这里不预设未经验证的销量或售价。

## 固定版本与资源交付

PicoClaw 基线保持 v0.3.1；官方 launcher 一并锁定。客户盘不在启动、后台或工作中自动更新程序。下载、打包与启动校验均以同一锁定清单为准。

传统工具和驱动逐项附名称/版本、来源、SHA-256、许可证及通知、平台与实际验证范围。Windows 工具不能计入 Mac 工具支持；资源存在也不代表驱动匹配、安装和回退已经实现。

新母盘由源码仓发行脚本统一生成，不手工拼接平台产物。既有用户数据和旧发行归档保留；更换发行版本时使用新目录、显式迁移和可恢复备份，不直接覆盖正在运行的 U 盘。

## 再分发与隐私

- 本项目自有代码采用 MIT，可用于商业交付；第三方工具与组件逐项按原许可履约。
- 分发 GPL/LGPL 二进制前检查完整对应源码、构建材料和通知要求；仅附一个不含依赖的源码 ZIP 不自动代表全部义务已满足。
- 未允许再分发的工具只提供官方入口，例如 Sysinternals。
- 发货模板中的 `data/` 必须为空；不能复制开发者的钱包或让多位客户共用同一个 Key。
- 自带 API Key 是用户个人配置；若赠送云端额度，应逐客户独立开通、单独说明额度和服务条件。
- 发货版附版本清单及校验值；更新保留用户数据。支持内容、期限、硬件适配范围和售后方式在购买前说明。
