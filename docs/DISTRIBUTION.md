# 网管版交付范围

只交付 Windows x64 主程序、固定版本 PicoClaw 和相关许可证。PicoClaw 是可选 AI 接口的运行时；电脑检测、系统工具与报告不依赖 AI、账号或付费额度。

公司提供并批准 API 地址、模型与访问凭证。只有操作员发送 AI 问题或点击连接测试才请求该 API。AI 问题会携带会话及相关诊断证据；请按公司数据规则使用。密钥、备份和维护记录随盘保存，当前未加密。

没有第三方工具库、模型权重、驱动包或救援镜像。旧盘上的钱包、模型、工具和对话不自动删除；本版不再读取钱包或启动离线模型。旧云设置在内存中显示为空的公司 API 配置，只有用户保存新设置才写入且保留备份。

以全新空目录制包，验证 ZIP 内的文件清单、版本和 SHA-256。GitHub 的 v0.5.0-preview 为本次网管预发布版；产品页与历史 Release 保持原版。每次制包必须来自干净的合并提交，程序嵌入的源码提交须与清单相同。
