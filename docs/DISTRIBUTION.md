# 开源软件与预装实体盘

## 产品价值

源码免费公开；实体盘销售的是硬件、预下载资源、可复现配置、出厂检测和约定的支持。可以同时提供免费下载自装与付费成品盘，不把已公开的上游软件宣传为独家自研模型。

建议先验证两种交付：

| 方案 | 内容 | 适用需求 |
| --- | --- | --- |
| 维护工具盘 | 已适配的维护工具、我们的启动器与说明 | 希望插上就能查问题、打开工具 |
| 离线 AI 盘 | 工具盘 + 适配运行时 + 少量精选模型 | 下载慢、不愿配置、需要离线使用 |

大体积模型可考虑外置 SSD。U 盘读速影响加载，生成速度主要取决于电脑的 CPU/GPU、内存和上下文长度；不能承诺任意旧电脑都流畅运行大模型。

定价以硬件采购、写盘与检测、包装物流、平台费用、售后和合理利润为基础。先小批量验证购买意愿、退货原因和支持成本，再扩大型号；这里不预设未经验证的销量或售价。

## 模型交付

当前已适配的是 Qwen3.5-0.8B Windows CPU 选装包。更大模型仅是下一阶段候选，不能仅放入文件就称为“已支持”。候选如 Qwen3.5-4B / 9B，需分别核验模型及量化来源、许可证、运行时版本和真实硬件表现。

每款模型随盘提供：上游名称与版本、官方来源、量化格式、SHA-256、许可证及通知、测试电脑配置、加载耗时和实际生成表现。按实际测试推荐内存，不把文件大小直接当作运行内存要求。

不要默认把几十款模型塞满整盘。先提供一个轻量档和一个效果档，方便用户选择。无法离线工作的云端服务必须明确标识。

## 再分发与隐私

- 本项目自有代码采用 MIT，可用于商业交付；第三方工具、模型与组件逐项按原许可履约。
- 分发 GPL/LGPL 二进制前检查完整对应源码、构建材料和通知要求；仅附一个不含依赖的源码 ZIP 不自动代表全部义务已满足。
- 未允许再分发的工具只提供官方入口，例如 Sysinternals。
- 发货模板中的 `data/` 必须为空；不能复制开发者的钱包或让多位客户共用同一个 Key。
- 自带 API Key 是用户个人配置；若赠送云端额度，应逐客户独立开通、单独说明额度和服务条件。
- 发货版附版本清单及校验值；更新保留用户数据。支持内容、期限、硬件适配范围和售后方式在购买前说明。
