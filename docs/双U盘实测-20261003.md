# 0.4 双 U 盘实测

产品构建来源：`a54aaa723162016ceb46931d80f2dd7a236a5144`，版本 `0.4.0-preview`，原生 PicoClaw `0.3.1`。测试日期 2026-10-03，同一台 Windows 11 电脑，两块独立物理 USB 存储器。

## 目标和结果

| 项目 | E 盘 | F 盘 |
| --- | --- | --- |
| 设备 | ORICO EB05-128GB | USB Sandisk 3.2Gen1 |
| 文件系统 | exFAT | NTFS |
| 交付目录 | `E:\虾盘 U盘精灵 0.4-716a4c` | `F:\虾盘 U盘精灵 0.4-716a4c` |
| 程序文件 SHA-256 | 8 项一致 | 8 项一致 |
| 本机服务首次可访问 | 0.263 秒 | 0.677 秒 |
| 真实启动项读取 | 15 项，无警告 | 15 项，无警告 |
| CLI / HTTP 启动项结果 | 一致 | 一致 |
| 原生 PicoClaw 自带 API + 工具调用 | 通过 | 通过 |
| 重启后设置、对话恢复 | 通过 | 通过 |
| 界面测试连接、保存、重载 | 通过 | 通过 |
| 界面 `/启动项` | 通过 | 通过 |
| 浏览器未捕获脚本错误 | 0 | 0 |
| 真实虾盘云问答 | 成功，7.538 秒 | 成功，3.104 秒 |

启动时间为本次电脑上实测的进程启动至本机 HTTP 可访问时间，不代表其他电脑或浏览器首屏性能。

从工作区启动盘内 EXE，不传 `--root`，确认便携根仍是 EXE 所在 U 盘目录。关闭 E 盘程序，将它的测试 `data/` 复制到 F 盘，确认模型选择和完整对话一致，然后在 F 盘继续调用原生工具。此项验证了实际 E→F 路径变化，未验证另一台电脑或拔插分配新盘符。

自带 API 使用 localhost fixture、虚构密钥和带斜线的模型 ID；真实 PicoClaw 执行真实启动项读取。没有把 fixture 回复算作云模型结果。密钥在设置接口与对话中被隐藏，每轮临时安全配置清理通过。

## 两次真实模型请求

用户单独明确授权使用旧 E 盘钱包，向 `https://api.u-claw.org.cn` 发送两次简短问答。分别由 E、F 盘上的程序通过原生 PicoClaw 调用 `deepseek-v4-flash`，返回“虾盘便携测试成功”。查询余额从 952,895 变为 946,826，减少 6,069 token。

钱包仅在测试动作中临时注入，通过 `finally` 删除，并扫描测试数据确认没有遗留真实密钥。没有轮换凭证、创建钱包或修改原钱包文件。最终交付目录不预装该钱包。

## 原生窗口和界面

从 E 盘程序调用 `tools.launch`，设备管理器与系统信息的真实 Windows 窗口均出现。设备管理器经过 Windows 提权启动分支；这不表示整个 AI 进程获得管理员权限。没有禁用启动项、清理磁盘、安装驱动或修改注册表。

独立 Edge / Playwright 会话验证两盘页面：自带模型选择、连接测试、保存重载、密钥输入框不回显、通过输入框查询启动项。截图已人工查看。测试脚本使用元素等待，未降低页面 CSP。

## 交付状态

两盘均保留原有内容，无需格式化。仅清理本次新建目录的测试 `data/`，恢复空白用户状态；重新验证 8 个程序文件。入口都是各交付目录内的 `虾盘.exe`，根目录只有主程序、`app/` 和 `data/`。第一次使用可设置自己的 API，或从旧版备份钱包后在新版填入。

## 证据与复现

本地 `evidence/`（不纳入 Git）保存：

- `genie-usb-targets.json`：盘符、硬件身份、来源提交与新目录。
- `genie-usb-results.json`：盘内进程、原生工具、自带模型、重启、跨盘接续。
- `genie-usb-cloud-results.json`：两次真实云端响应、余额与凭证清理结果。
- `genie-usb-ui-results.json`、`genie-usb-*-settings.png`、`genie-usb-*-startup.png`：界面证据。
- `genie-usb-tool-launch-results.json`：原生工具窗口观察。
- `genie-usb-final-state.json`：测试数据清理、默认设置及最终文件校验。

`python scripts/verify-genie-usb.py` 读取已核验目标清单，要求两个新建测试目录的 `data/` 均为空。脚本只使用本机模型 fixture，不读取真实钱包、不格式化、不清理任何盘；执行前须核对清单的当前磁盘身份，执行后仅清理本次创建的测试数据。可选 `--hold-for-ui` 在有界时间内保留服务，供交互式界面验收。
