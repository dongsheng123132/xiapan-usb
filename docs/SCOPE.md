# 产品取舍：公司网管

目标用户是到办公电脑现场处理故障的公司网管。单次价值：找到可核对的故障证据、打开正确的系统工具、把排障记录带走。

| 保留 | 删除及原因 |
| --- | --- |
| Windows 体检、进程、启动项 | Mac 完整包与 Linux 交付目标：多份系统适配和验收成本 |
| 网卡驱动信息、只读分层网络诊断 | 驱动资源库存、资源扫描和启动救援入口：没有闭合的安装/恢复能力 |
| 7 个 Windows 原生工具入口 | 6 款便携工具、19 项推荐及救援资源目录：上游版本、授权、哈希和配置维护 |
| 随盘会话、报告与确认 | 自我复制的便携体检工具安装：不提供额外排障价值 |
| 一个可选公司 API + PicoClaw | 钱包、充值、轮换、云模型列表、多套对话引擎、离线大模型：远离公司网管流程且维护面大 |
| 中英文界面 | 通用写作/翻译入口：目标用户与场景分散 |

新增需求闸门：已有具体网管问题和复现证据；第一版能在一个工作日内验证；删掉后不会妨碍主流程的功能不进默认产品。公开发行前还需另一台公司环境 Windows 电脑验证。
