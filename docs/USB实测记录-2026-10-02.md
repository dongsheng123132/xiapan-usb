## 界面操作验证

从 F 盘启动本机服务，通过真实浏览器完成：

1. 首页体检 → 真实信息弹窗 → 保存报告 → 维护记录可读。
2. 安装页 → 明确确认安装到本盘 → 显示安装进度 → 文件及启动验证通过。
3. 首页首次提问 → 自动校验并启动盘内模型 → 显示本地 AI 回答（此问题回答 2.7 秒）→ 点击下一步进入真实体检。
4. 离线 AI 页停止模型 → 首页使用维护向导提问，不调用模型。

首页与问答截图、原始 JSON 和日志留在本机 evidence/，默认不提交其中的本机路径、设备详情和原始输出。
