# 虾盘 U 盘精灵 0.4

2026-10-03。代码源仍为本仓库；没有修改旧 ClawX 仓库、原 E 盘目录或用户钱包。

## 沿用的旧产品逻辑

参考本机 `Desktop/claude/u-claw/v2/u-clawx-portable --4.0版本`（读取时 HEAD `6349050c`）：

- `electron/utils/paths.ts`：程序目录决定便携根，`data/` 保存用户状态；子进程显式指定 home/config 路径。
- `harness/specs/rules/provider-model-selection-authority.md`：用户选择的模型是权威值，保留模型 ID 中有意义的斜线，不被旧运行时记录覆盖。
- `harness/specs/tasks/provider-switch-api-protocol-validation.md`：提供商配置要转换成目标运行时实际接受的协议；非法配置在写入前拒绝。
- `v2/__USB_PACKAGE_DESIGN.md`：单入口、开箱运行、发行包只放干净状态。旧文件中的历史体积和目录名称不作为当前包参数。

## 这轮实现

- 自带 OpenAI 兼容 API 和虾盘云模型选择；设置、密钥与备份在本盘。设置查询不返回密钥。每轮 PicoClaw 派生配置使用选定地址、模型及相应凭证，不借用钱包密钥。
- 原子保存前留底，带设置修订号，拒绝陈旧覆盖。改端点不沿用旧密钥；损坏配置原样保留。
- `settings.model.test` 发送一次无副作用工具调用探测，只验证，不保存。模型无权调用设置动作。
- `startup.inspect` 读取常见 Windows 自启来源及可判定的 StartupApproved 状态。无可判定状态显示待核实，不宣称全部自启。`/启动项`、GUI、PicoClaw MCP 共用同一实现。
- 原生工具增加任务管理器；用户直接点击打开即授权该次打开，AI 请求仍生成确认卡片。保留启动错误，只有 Windows 错误 740 才对选定原生工具请求 UAC，不提高整个 AI 进程权限。
- 首页集中对话、模型设置和工具；历史抽屉默认不占空间、不参与键盘焦点；空资源分类不显示。
- Windows 精简包只放主程序、`app/`、空 `data/`。保留原 `runtime/` 布局兼容，新包运行时在 `app/runtime/`。不附带官方 Launcher 和离线权重，不复制用户凭据。

## 可复现验证

```powershell
go test ./...
.\scripts\build.ps1
python scripts/verify-genie.py
python scripts/verify-pico-adapter.py
python scripts/package-genie.py
```

`verify-genie.py` 使用真实 PicoClaw v0.3.1 和 localhost 模型 fixture，验证自带模型 ID（含斜线）、密钥隔离、工具调用、原生启动项读取、临时凭证清理、目录搬迁后的配置及对话续用。回放不会调用付费 API，也不会写系统启动项。

`verify-pico-adapter.py` 保留原有钱包适配、MCP 确认和禁止模型绕过确认的回归。

界面在新建测试目录用独立浏览器会话验证；只填写虚构密钥，不提交到外部服务。实际运行证据存于本地忽略目录 `evidence/`。发布包的文件哈希及来源提交写入 `app/manifest.json`，ZIP 外附 SHA-256。
