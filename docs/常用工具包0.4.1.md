# 常用工具包 0.4.1

用户选择优先补齐启动项、磁盘、压缩和进程。保留精简版，另提供 `--with-tools` 常用工具包；盘根仍只有 `虾盘.exe`、`app/`、`data/`。

## 实现

| 用途 | 当前提供 |
| --- | --- |
| 启动项 | 原有 `startup.inspect` 读取常见 Run、Run32、启动文件夹；任务管理器供用户手动管理 |
| 进程 | 原有 `processes.inspect` 读取进程占用；任务管理器、资源监视器入口 |
| 磁盘 | Windows 磁盘清理入口；新增 WinDirStat 2.9.0 Portable 空间分析 |
| 压缩 | 新增 PeaZip Portable 11.3.0 |
| 系统 | 设备管理器、系统信息、事件查看器入口 |

共 6 个系统工具入口、2 个随盘第三方工具。GUI、CLI、PicoClaw 仍调用同一个 `tools.launch`。用户点击打开即授权启动；AI 提议需通过现有确认卡片。工具后续操作由用户在原生界面完成，未增加自动清理、关闭启动项或终止进程。

准备脚本固定官方版本与归档 SHA-256，保留上游许可证和项目源码归档。启动时按程序内固定清单检查不可变文件，入口和参数不可由模型自定义。WinDirStat 相邻 INI 启用便携设置；PeaZip 使用官方 Portable 包。它们的可变配置分别在 `app/tools/windows-x64/windirstat/WinDirStat.ini`、`app/tools/windows-x64/peazip/res/conf/`，更新时应保留。

## 平台与凭据

完整发行包当前仅 Windows x64。macOS ARM64/x64、Linux x64 通过主程序交叉编译，不等于具备相应 PicoClaw、第三方工具运行时或通过实机验收。后续应分别准备各平台程序，共享数据，不能把 Windows EXE 作为三系统入口。

自带 API 的地址、模型 ID、密钥保存在 `data/settings/model.json`，旧设置备份可能也含密钥，当前是明文。程序不设置到期时间、不绑定电脑；换到兼容电脑，只要服务可达、凭证有效即可继续使用。API 服务商的到期、余额和网络限制仍生效。`localhost` 指当前电脑，不会随 U 盘携带模型服务。

## GitHub 上可借鉴的做法

- [PortableApps Launcher](https://github.com/PortableApps/Launcher) 的启动器配合 [App/Data 与盘符变量](https://portableapps.com/manuals/PortableApps.comLauncher/ref/envsub.html)，处理数据随盘和位置变化。
- [Portapps](https://github.com/portapps/portapps) 用启动器包装 Windows 便携应用，应用和依赖按需提供。
- [UniGetUI](https://github.com/Devolutions/UniGetUI) 管理 WinGet、Scoop 等包管理器，适合安装和更新，不能直接等同于全部软件随 U 盘便携运行。
- [Ventoy](https://github.com/ventoy/Ventoy) 解决镜像启动；与已经进入桌面后的便携工具包是两个层次。

本轮采用小型 AI 核心加可选传统工具包。离线模型与救援镜像继续作为独立选装资源。未执行公开发布、格式化或写入引导。
