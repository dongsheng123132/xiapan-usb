# 维护场景覆盖表

本盘适用于**能进入 Windows 的 x64 电脑**。可以离线检查本机、打开随盘工具、阅读常见故障指引；它没有“所有故障自动修好”的能力。复制文件夹不会把 U 盘变成启动盘。

“检查”表示读取信息；“工具”表示准备了手动操作入口；“指引”表示说明处理顺序。工具就绪不等于已经完成清理、恢复或修复。实际操作前先辨认目标设备和需要保留的数据。

## 网络诊断与本地 AI 的使用边界

“网络检查”只读取本机接口与地址，可以在完全断网时运行。“网络诊断”和“断网急救诊断”会尝试 DNS、网关、网页或服务探测，用于定位连通性；它们不自动修改网络，但也不属于完全不发出网络请求的检查。本轮验收没有对真实外部地址执行这两种诊断。

已识别的硬盘异常、误删、有线断网和组织设置报错优先返回**维护知识指引（未调用模型）**。这些是已核对的固定资料，不能当成小模型生成质量的证明。其他描述可能进入通用 Qwen3.5-2B 模型；该模型未做电脑维修专项微调，实测仍有事实错误，只适合作参考，不能独立决定修复操作，也不能保证识别所有危险描述。
