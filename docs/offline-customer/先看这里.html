WINDOWS x64 · 主维护入口不用账号、不用联网

电脑断网，维护照常开始。

先检查，再判断。维护指引和本地小模型供你参考，检测工具提供判断所需的证据。

第一次使用

  1. 把整个“虾盘离线维护盘”文件夹复制到 U 盘。不能只复制启动器；保留 app、models 和其他子目录。
  2. 在能进入 Windows 的电脑上，双击 开始维护.cmd 或 虾盘.exe。默认打开本盘离线 AI，不需要 Codex、云端账号或 API Key。
  3. 先点“体检”“驱动”或“工具”，也可以输入 /体检、/驱动、/进程。首次问 AI 时会校验并加载模型，请耐心等待。
  4. AI 暂时不能运行时，仍可从“02-离线工具”直接打开各项工具，或在主程序选择“本地工具”。
  5. 关闭维护程序和第三方工具，等硬盘读写结束后再安全弹出 U 盘。

适用于 Windows x64。建议 8 GB 及以上内存；小模型的运行速度主要取决于电脑 CPU、可用内存和 U 盘读速。旧电脑兼容性需现场确认。本包不是可启动的 WinPE 或重装盘。

旧网卡离线应急

“05-旧网卡离线驱动-可选”附 3DP Net 21.01 官方完整包，内置传统有线和无线网卡驱动池，无需先联网下载驱动。它是 2021 年的旧库，不是面向所有 Windows 11 或新网卡的万能包。先看该目录说明，记录硬件 ID 和系统版本，由维护人员确认后手动使用。本次只核验文件来源、归档及真实驱动内容，没有在客户硬件上安装测试。

客户截图这类问题怎么查

Codex 提示“无法加载组织设置”，只能说明该应用尚未取得所需配置。单凭这个提示不能断定整台电脑已断网，也不能认定一定是防火墙。

  1. 观察网络图标，确认 Wi-Fi/网线连接；用同网络另一台设备对比。
  2. 打开本盘“驱动”检查：网卡是否存在、是否报故障码，有无未知设备。
  3. 点“断网急救诊断”，按网卡 → 网关 → DNS → 网页 → 代理逐层看结果。此按钮会尝试访问网络以验证可达性，但不修改设置。
  4. 如果其他网站正常、仅 Codex 不工作，检查该应用要求的账号、代理和网络访问；组织配置与账户问题需联网后恢复。
  5. 需要临时联网，可试有线连接或手机 USB 共享；先确认流量和客户允许。没有匹配驱动时，先读取硬件 ID，在有网电脑上从厂商官网准备对应驱动。

不要因一个报错就重置全部网络或关闭安全软件。微软将“网络重置”列为靠后的排障步骤，因为它会影响既有网络配置。

维护时先保护数据

  • 硬盘异响、频繁掉盘、SMART 警告：新出现的咔哒/磨擦异响伴数据丢失、掉盘或读错误时，先停用；重要数据应关机并避免反复通电，交专业恢复人员评估。不要先普通大批量复制、扫描、压测或修复。SMART 单独告警的处理须结合实际症状，不等同于已确诊物理故障；显示正常也不能排除故障。
  • 文件误删：停止向原盘写入。恢复结果放到另一块盘，不能写回正在恢复的盘。PhotoRec 可能无法保留原文件名或目录结构。
  • C 盘满：先用 WinDirStat 识别大目录，再确认文件归属。不要按 AI 建议直接删除 Windows、Program Files 或未知系统文件。
  • 系统文件异常：先保留日志、备份数据。系统修复可能需要管理员权限及匹配的 Windows 安装源；不能承诺所有修复在无网时完成。
  • 网卡缺驱动：可尝试“05-旧网卡离线驱动-可选”中的旧驱动库；没有匹配项时仍需另备厂商驱动。先在“驱动”检查或设备管理器中记录硬件 ID、电脑型号、Windows 版本及架构；在另一台有网电脑上从电脑或网卡厂商官网下载匹配驱动，核对签名和来源，再复制到本盘 drivers/。由维护人员确认型号后手动安装，本盘不会自动安装。
  • 无法进入 Windows：主程序不能运行；需另行准备可启动救援环境。BitLocker 加密盘还需要合法的恢复密钥，维护盘不能绕过加密。

关于离线模型与大龙虾

随盘模型文件约 1.28 GB，面向轻量中文问答。维护知识会进入模型上下文；这是通用模型配维护知识，不是电脑维修专项训练模型。实测自由问答内容质量未通过，不能当维修专家。对于已识别的硬盘异响、误删、有线断网和“无法加载组织设置”等问题，程序优先显示已核对的固定维护指引，并明确标注“未调用模型”；其余问题由模型作参考回答。分流不能识别所有描述，也不保证模型回答正确；以真实检测和专业判断为准，模型没有自动执行系统修改的权限。

“03-大龙虾-可选”采用独立构建的 U-DSH 0.2.2，用 Electron 桌面窗口承载 Harness WebUI。请解压到本机 NTFS 新目录后运行；离线启动已通过，尚未完成与本盘小模型的整机联调。旧 0.2.0 首发包缺少必需文件，已弃用。

U-DSH 的设备钱包、“一键开通并充值”属于需要联网的云服务功能，不是离线维护的前置条件。在本机隔离副本及本地模拟服务中，手动钱包入口、开通按钮、配置保存、充值页链接、绑定不重复和服务不可达时界面仍能打开均已验证；没有创建真实钱包或付费。新版还修复了新钱包零余额时未自动打开钱包的问题，最终包重新解压后的自动弹窗、一键充值入口、钱包配置及模拟断网启动均已通过，详情见随盘验收记录。断网维护请使用根目录入口。

启动救援材料还需要哪些准备

“04-启动救援准备”提供 Ventoy 及对应源码、许可证等准备材料。它们不是已经安装好的启动盘；安装引导可能改写 U 盘分区，须先备份并确认目标设备。

当前未附完整 SystemRescue ISO；未完成的下载没有放入客户母盘。本盘未附 WinPE、Windows 安装镜像或现代全型号网卡驱动库；旧网卡驱动补充包在“05”目录。电脑进不去 Windows 时，需要提前取得并校验合适的救援镜像、另行制作启动环境及实机试启动；仅复制维护文件夹不能完成这些步骤。

复制与售后记录

这是干净母盘：data/ 初始为空。使用后，对话、诊断报告和工具配置会写到盘内。不要把客户用过的盘反向覆盖母盘；不要将一位客户的账号、报告或聊天复制给另一位客户。

发货前可在 PowerShell 运行根目录 校验母盘.ps1；它只读检查文件缺失、变化及额外文件，不修改系统。上游许可证、对应源码和资源来源保存在 app 及相关材料目录下。

主维护程序已在本机的真实 G: exFAT U 盘副本上验证：模型加载约 4.766 秒、一轮真实回答约 12.953 秒，中文带空格目录迁移后仍可只读体检，母盘数据保持为空。没有拔网线、禁用网卡或在第二台电脑验证；这些速度也不是旧电脑的性能承诺。
