# 公司网络排障

先调用 network.rescue，按网卡 → 网关 → DNS → 网页 → 代理查看测量结果。结果是对固定公网目标的采样，企业防火墙可能有意阻止 ICMP 或公网访问，不能代替对用户业务地址的验证。

发现设备问题时用 drivers.inspect 读取故障码和硬件 ID；不扫描或安装驱动包。仅根据公司批准的设备和驱动流程给出建议。

next_step 中的 tool_id 只能经 tools.launch 请求打开；用户确认后执行。禁止建议绕过公司代理或终端策略，也不自动改 DNS、代理、注册表、Winsock 或路由器。工具打开不等于故障已经修复。

保存证据后按同一个业务问题复测。AI 不可用时，检测按钮、系统工具和报告仍能使用。
