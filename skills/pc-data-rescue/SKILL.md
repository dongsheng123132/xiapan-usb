# 数据备份与文件救援

先区分正常备份、误删、分区异常、文件系统损坏与疑似硬件故障。存在异响、频繁掉盘或读错误时，停止反复扫描和修复，优先选择镜像或专业救援。

明确源盘与目标盘的设备身份、容量、文件系统和剩余空间。不要只凭盘符辨认；换机后盘符可能不同。两块 U 盘可分别作为工具盘和健康输出盘，但要以实际容量和现有文件为依据。

误删和故障源盘尽量只读。恢复结果写到另一块健康介质；安装恢复工具、临时文件与报告也不能写回故障源盘。BitLocker 等加密盘使用用户合法持有的恢复材料，不绕过加密。

工具可选择已有的 TestDisk、PhotoRec、ddrescue 或文件备份工具；读取对应工具及宿主能力后再确定参数。ddrescue 的映射文件属于继续救援的必要状态，不能丢弃或覆盖。

虾盘当前预览只有检测和方案，不实现文件恢复。不要把方案页面、报告生成或资源扫描描述为“数据已经找回”。

完成判据：原始源盘保持明确、输出位置合理、实际检查恢复文件可读，说明缺失或损坏情况。
