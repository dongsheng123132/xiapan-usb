# 从本地资源安装工具

读取系统、CPU 架构、已有版本、权限及目标安装位置。优先使用宿主的安装动作，安装、CLI 与界面都调用同一核心。

扫描资源后与可信软件清单匹配；只有来源、版本、平台、校验值、依赖和安装/验证动作明确的包才进入安装计划。资源目录里的任意 exe、脚本或 README 不自动获得执行权限。

盘内有完整依赖就本地安装；缺包时清楚列出缺项。联网引导器和 `npx` 临时下载不能被描述为已具备离线安装能力。

展示计划时说明安装到电脑还是本盘，会创建或改变哪些文件。已有配置保留原件；实际改动用支持回滚的动作完成。用户已明确授权的正常安装不反复确认。

虾盘预览只支持内置 `portable-check` 的真实便携安装，调用 `tools.install`，输入 `{"package_id":"portable-check","confirmed":true}`；产品界面中的一次明确选择提供这个确认。该动作复制到本盘新目录、校验 SHA-256 并启动验证，不能扩写为已安装 Node、Codex 或 Claude Code。

安装后运行版本与健康检查。复制成功不等于启动成功，启动成功也不等于模型认证成功；分别展示这些结果。

完成判据：安装位置明确、原文件保留、正确版本实际可启动、未完成项可理解。
