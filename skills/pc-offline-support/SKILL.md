# 离线电脑维护知识

这些是随盘参考知识，不是专项训练模型。先保护数据，再定位原因。只有真实检测或用户明确提供的现象可当证据；模型回答不能代替检测。每次先做一个最能区分原因的只读检查，记录原状态后再考虑修改。

## 断网、代理与 DNS
先问：所有软件断网，还是只有浏览器或一个 AI 软件失败？电脑端依次看网线/Wi-Fi、网卡和驱动、IP/网关、DNS、代理、系统时间、目标服务。飞行模式只适用于电脑无线连接；有线以太网不靠飞行模式排障。路由器和交换机没有这里所说的电脑飞行模式：先查看供电、网线、上联网口与链路指示灯，不凭灯亮就认定互联网正常。169.254 地址常见于未取得 DHCP 地址，但不能单凭它确定网卡坏了。网卡故障码 0 不证明互联网可用。
浏览器打不开而聊天软件能用，可能是代理、DNS 或浏览器问题。127.0.0.1 代理可能属于正常 VPN 软件；不要直接删除。公司电脑应保留企业 DNS、代理和 VPN 策略。先确认代理程序是否运行、原配置是什么。DNS 失败不能直接认定必须改公共 DNS。
“无法加载组织设置”只说明应用未取到必要配置；先区别整机断网、服务不可达、代理/时间错误、账号权限。不要删除登录数据或关防火墙。网络恢复后再重试。401/403 是认证或权限线索，429 是限流或额度线索。
系统时间错误可能影响 HTTPS 证书或身份认证，不能把时间错误当成 DNS 解析失败的证据。不要声称关闭防火墙会阻断必要通信；建议保留安全防护是为了保护系统。
缺网卡驱动时按电脑硬件 ID、整机型号、Windows 版本和架构核对厂商支持的驱动；驱动版本号不需要与 Windows 版本号相等。路由器固件属于路由器本身，按路由器型号和硬件版本匹配，不要求与 Windows 版本一致，也不能当作电脑网卡驱动安装。断网不等于需要升级固件，先定位原因。可尝试有线或手机 USB 共享网络，后者也可能需要驱动。

## 磁盘、SMART 与数据恢复
磁盘有异响、掉盘或读错误时，停止反复扫描、清理和修复，先考虑镜像或专业救援。SMART 告警是风险线索；SMART 正常也不保证无故障。USB 转接桥可能读不到 SMART。
新的咔哒/磨擦声伴文件丢失属于疑似物理故障：停止使用，重要数据应关机并避免反复通电，咨询专业数据恢复。不能因为异响暂时消失就认定只是临时故障，也不能无条件建议普通大批量复制。由具备设备和经验的人员评估是否适合镜像。
误删或分区异常时减少源盘写入，不向源盘安装恢复软件。恢复文件保存到另一块健康介质；按型号、容量确认源盘和目标盘，不能只看盘符。不格式化、不初始化、不在疑似故障盘上先做文件系统修复。加密盘需要用户合法持有的恢复密钥。

## Windows 与启动故障
系统能启动时先做体检、查看事件与磁盘空间，再决定是否修复系统文件。SFC 和 DISM 不是数据恢复工具；离线修复可能需要匹配版本/架构的 Windows 安装源，不能保证脱网自动修好。先备份重要数据，不反复重置网络或重装驱动。
系统无法启动时，这个 Windows 程序也不能运行，需要预先制作并测试的独立启动救援环境。仅复制文件、ISO 或格式化为 exFAT 不会使 U 盘可启动。BitLocker 恢复材料、备份和源/目标盘身份先确认，再考虑引导修复或重装。
